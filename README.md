# jrnf.github.io

Personal site for Jeff Forbes, built with [al-folio](https://github.com/alshedivat/al-folio) (Jekyll) and published with GitHub Pages.

- Edit the home page in `_pages/about.md`, consulting in `_pages/consulting.md`, and the CV page in `_data/cv.yml`.
- The downloadable CV is `assets/pdf/jeff-forbes-cv.pdf`; the profile photo is `assets/img/prof_pic.jpg`.
- Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and publishes it to the `gh-pages` branch.
